One-page syntax and mental-model reference for Lesson 0001. Keep open or print while writing egui panels.

1. The Mental Model (One Frame = One Function Call)

  ┌─────────────────────────────────────────────────────────────────────┐
  │ Your Rust Struct (Persistent State across frames)                   │
  │   struct PcbReviewerApp { show_top_copper: bool, ... }              │
  └───────────────────┬─────────────────────────────────────────────────┘
                      │  1. eframe calls update(&mut self, ctx, frame)
                      ▼
  ┌─────────────────────────────────────────────────────────────────────┐
  │ SidePanel::left("layers").show(ctx, |ui| {                          │
  │   ui.checkbox(&mut self.show_top_copper, "Top Copper (F.Cu)");      │
  │     ├─► Reads self.show_top_copper to draw checked/unchecked box    │
  │     └─► If clicked this frame, flips self.show_top_copper in place! │
  │ });                                                                 │
  └───────────────────┬─────────────────────────────────────────────────┘
                      │  2. CentralPanel reads updated state immediately
                      ▼
  ┌─────────────────────────────────────────────────────────────────────┐
  │ CentralPanel::default().show(ctx, |ui| {                            │
  │   if self.show_top_copper { /* paint red F.Cu traces */ }           │
  │ });                                                                 │
  └─────────────────────────────────────────────────────────────────────┘

2. Canonical eframe Skeleton

use eframe::egui;

// 1. Persistent domain & view state lives in your struct
pub struct PcbReviewerApp {
    pub show_top_copper: bool,
    pub show_bottom_copper: bool,
    pub show_silkscreen: bool,
}

impl Default for PcbReviewerApp {
    fn default() -> Self {
        Self {
            show_top_copper: true,
            show_bottom_copper: true,
            show_silkscreen: true,
        }
    }
}

// 2. Implement eframe::App to define the per-frame UI
impl eframe::App for PcbReviewerApp {
    fn update(&mut self, ctx: &egui::Context, _frame: &mut eframe::Frame) {
        // Always declare SidePanels / TopBottomPanels BEFORE CentralPanel!
        egui::SidePanel::left("layer_inspector").show(ctx, |ui| {
            ui.heading("PCB Layers");
            ui.checkbox(&mut self.show_top_copper, "Top Copper (F.Cu)");
            ui.checkbox(&mut self.show_bottom_copper, "Bottom Copper (B.Cu)");
            ui.checkbox(&mut self.show_silkscreen, "Top Silkscreen (F.SilkS)");

            if ui.button("Copper Only").clicked() {
                self.show_top_copper = true;
                self.show_bottom_copper = true;
                self.show_silkscreen = false;
            }
        });

        egui::CentralPanel::default().show(ctx, |ui| {
            ui.label("2D PCB Canvas Viewport");
        });
    }
}

3. Common Panel & Widget Signatures

Pattern Rust Code Why It Works This Way
Two-way boolean toggle ui.checkbox(&mut self.flag, "Label") Borrows self.flag mutably for the duration of the call; flips the boolean if clicked and returns a Response.
Momentary action button if ui.button("Reset").clicked() { ... } Buttons don't store a boolean; they return a Response whose .clicked() method is true on the frame the click occurred.
Panel ordering rule SidePanel first, CentralPanel last CentralPanel claims all remaining area left over in ctx after outer panels allocate their widths/heights (docs.rs).
