Glossary of Rust & egui Terms

Canonical definitions used across all lessons and reference sheets. Designed for quick screen lookup and clean printing.

1. Core GUI Paradigms

Term Definition PCB / Schematic Analogy
Immediate-Mode GUI (IMGUI) A UI paradigm where widgets are not persistent objects in memory. Instead, your application state lives in a plain Rust struct, and every frame you call functions like ui.checkbox(...) or ui.button(...) that simultaneously query input and emit draw commands (docs.rs/egui). Redrawing the active copper and silkscreen layers directly from the board data model on every display refresh.
Retained-Mode GUI A traditional UI paradigm (DOM, Qt, Flutter widget trees) where the framework stores a persistent graph of widget objects with their own internal state that must be synchronized via callbacks or listeners. Maintaining a separate physical copy of every switch and indicator LED and wiring event listeners between them.

2. Essential Rust Mechanics Used by egui

Term & Syntax Definition Where You See It in egui
Manifest (Cargo.toml) The configuration file for a Rust package defining its metadata, external dependencies (like eframe), and compiler optimization profiles (Cargo Book). Declares eframe = "0.33" and [profile.dev.package."*"] opt-level = 2.
Struct (struct) A composite data type that groups named fields together into a single unit of ownership (Rust Book §5.1). struct PcbReviewerApp holds your persistent layer toggles, zoom level, and netlist state across frames.
Default Trait (Default) A standard library trait granting a type a canonical constructor (T::default()) for initial values (std::default::Default). impl Default for PcbReviewerApp sets show_top_copper: true when the reviewer boots.
Heap Box (Box<T>) A smart pointer that allocates a value of type T on the heap and owns it with a fixed-size pointer on the stack (Rust Book §15.1). Box::new(PcbReviewerApp::default()) hands your app instance to eframe::run_native.
Shared Borrow (&T) An immutable, read-only reference to a value of type T. Multiple &T references can coexist simultaneously, but the target cannot be mutated while borrowed (Rust Book §4.2). &egui::Context passed into update, or iterating over &self.traces to paint them on the canvas.
Mutable Borrow (&mut T) An exclusive, read-write reference to a value of type T. Allows a called function to both read the current value and modify it in place without taking ownership (Rust Book §4.2). &mut self in update(), and ui.checkbox(&mut self.show_top_copper, "Top Cu").
Closure (|ui| { ... }) An anonymous inline function that can capture variables (like self) from its surrounding scope. Arguments appear between vertical pipes |...| (Rust Book §13.1). egui::SidePanel::left("layers").show(ctx, |ui| { ... }) scopes which widgets belong inside that panel.

3. Key eframe & egui Types

Type / Method Role in the Frame Loop Primary Reference
eframe::run_native Opens a native desktop OS window, initializes the GPU renderer, calls your creation closure once to construct your app struct, and starts the event loop. eframe::run_native docs
eframe::App The trait your root application struct implements. Its core method, fn update(&mut self, ctx: &egui::Context, frame: &mut eframe::Frame), is invoked on every repaint. eframe::App docs
egui::Context (ctx) The top-level handle to egui for the entire window: manages input state (mouse/keyboard), fonts, style, memory of widget IDs, and top-level panels (SidePanel, TopBottomPanel, CentralPanel). egui::Context docs
egui::Ui (ui) Represents a bounded rectangular region inside a panel or container with a layout cursor. You call widget methods (ui.heading, ui.checkbox, ui.button, ui.allocate_painter) on ui. egui::Ui docs
egui::Response Returned immediately by every widget call (e.g. ui.button("Reset").clicked() or .hovered()). Tells you how the user interacted with that widget during the current frame. egui::Response docs
