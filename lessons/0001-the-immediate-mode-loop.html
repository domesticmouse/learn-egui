Lesson 0001: The Immediate-Mode Loop & Mutable State (&mut)

Building the PCB Layer Visibility Inspector inside your eframe::App

In Lesson 0000, we created our pcb-reviewer Cargo crate and booted a native window with eframe::run_native. Now we will fill in the heart of that file—PcbReviewerApp::update—to build the Layer Visibility Inspector: toggling Top Copper (F.Cu), Bottom Copper (B.Cu), Silkscreen (F.SilkS), and the unrouted Ratsnest on and off.

In traditional retained-mode GUI frameworks (like HTML/React, Qt, or Flutter), you create checkbox widget objects once, attach event callbacks (onChange), and synchronize their internal state with your board renderer.See Emil Ernerfeldt's official Understanding Immediate Mode section in the egui documentation for why eliminating widget callbacks prevents out-of-sync UI bugs.

egui works completely differently. In egui, there are no persistent checkbox or button objects. Instead, your Rust struct holds the single source of truth, and on every frame, your eframe::App::update method runs from top to bottom.

1. Your Rust struct Is the Only State

Recall the PcbReviewerApp struct we initialized in Lesson 0000. Four bool fields track which PCB layers are currently visible: 

pub struct PcbReviewerApp {
    pub show_top_copper: bool,
    pub show_bottom_copper: bool,
    pub show_silkscreen: bool,
    pub show_ratsnest: bool,
}

2. Why egui Widgets Take &mut References

When eframe redraws your window, it calls:In eframe::App::update, &mut self is shorthand for self: &mut PcbReviewerApp—an exclusive mutable borrow of your struct for the duration of a single frame (Rust Book §4.2). 

fn update(&mut self, ctx: &egui::Context, _frame: &mut eframe::Frame)

Inside update, we place a left egui::SidePanel for our layer controls, followed by an egui::CentralPanel for our 2D PCB canvas. Look closely at what we pass into ui.checkbox: 

egui::SidePanel::left("layer_panel").show(ctx, |ui| {
    ui.heading("PCB Layers");
    ui.checkbox(&mut self.show_top_copper, "Top Copper (F.Cu)");
    ui.checkbox(&mut self.show_bottom_copper, "Bottom Copper (B.Cu)");
    ui.checkbox(&mut self.show_silkscreen, "Silkscreen (F.SilkS)");
    ui.checkbox(&mut self.show_ratsnest, "Ratsnest (Unrouted)");
});

Two Rust mechanics make those six lines work without a single callback:Always declare SidePanel and TopBottomPanel before CentralPanel. According to the CentralPanel docs, it claims all remaining space in ctx after outer panels have been laid out.

  1. The Closure (|ui| { ... }): .show(ctx, |ui| { ... }) takes an inline anonymous function (Rust Book §13.1) receiving a temporary &mut egui::Ui region. When the closure ends, ui is dropped—only your self struct persists to the next frame.
  2. The Mutable Borrow (&mut self.show_top_copper): Passing &mut grants ui.checkbox temporary read-write access to that single bool field. In one function call, ui.checkbox reads the boolean to draw the checkmark, checks whether the mouse clicked that rectangle this frame, and if so, flips the boolean in place before returning!

3. Making Button Actions Testable & Mutant-Proof

What about preset buttons like "Isolate Top Copper" or "Show All Layers"? When you click a button, ui.button("...").clicked() returns true for that single frame. If you extract the state transition into a method on PcbReviewerApp that takes &mut self, your update() loop stays clean and you can test and mutate every state transition with cargo test and cargo mutants (Testing & Mutation Cheat Sheet):Watch what happens if a test starts from a state where show_top_copper is already true and the other layers are already false, and then calls app.isolate_top_copper(): when cargo mutants replaces the body of isolate_top_copper with an empty no-op (), the test would still pass unless the starting state actually requires isolate_top_copper() to flip the fields! 

impl PcbReviewerApp {
    pub fn reset_layers(&mut self) {
        self.show_top_copper = true;
        self.show_bottom_copper = true;
        self.show_silkscreen = true;
        self.show_ratsnest = false;
    }

    pub fn isolate_top_copper(&mut self) {
        self.show_top_copper = true;
        self.show_bottom_copper = false;
        self.show_silkscreen = false;
        self.show_ratsnest = false;
    }

    pub fn show_all_layers(&mut self) {
        self.show_top_copper = true;
        self.show_bottom_copper = true;
        self.show_silkscreen = true;
        self.show_ratsnest = true;
    }
}

impl eframe::App for PcbReviewerApp {
    fn update(&mut self, ctx: &egui::Context, _frame: &mut eframe::Frame) {
        egui::SidePanel::left("layer_panel").show(ctx, |ui| {
            ui.heading("PCB Layers");
            ui.checkbox(&mut self.show_top_copper, "Top Copper (F.Cu)");
            ui.checkbox(&mut self.show_bottom_copper, "Bottom Copper (B.Cu)");
            ui.checkbox(&mut self.show_silkscreen, "Silkscreen (F.SilkS)");
            ui.checkbox(&mut self.show_ratsnest, "Ratsnest (Unrouted)");

            ui.separator();
            if ui.button("Isolate Top Copper").clicked() {
                self.isolate_top_copper();
            }
            if ui.button("Show All Layers").clicked() {
                self.show_all_layers();
            }
        });

        egui::CentralPanel::default().show(ctx, |ui| {
            ui.heading("PCB Viewport Ready");
            if self.show_top_copper {
                ui.label("Rendering Top Copper (F.Cu)...");
            }
            if self.show_bottom_copper {
                ui.label("Rendering Bottom Copper (B.Cu)...");
            }
            if self.show_silkscreen {
                ui.label("Rendering Silkscreen (F.SilkS)...");
            }
            if self.show_ratsnest {
                ui.label("Rendering Ratsnest (Unrouted)...");
            }
        });
    }
}

Interactive Lab 3: Cargo Verification & Catching a Missed Mutant cargo test + cargo mutants

Add the two unit tests below to your #[cfg(test)] mod tests block in src/main.rs. Notice why we start with show_top_copper: false and the other layers true before calling app.isolate_top_copper()—so when cargo mutants replaces isolate_top_copper or show_all_layers with a no-op (), the test assertions immediately catch the mutant! 

#[test]
fn isolate_top_copper_forces_only_top_copper_visible() {
    let mut app = PcbReviewerApp {
        show_top_copper: false,
        show_bottom_copper: true,
        show_silkscreen: true,
        show_ratsnest: true,
    };

    app.isolate_top_copper();

    assert!(app.show_top_copper);
    assert!(!app.show_bottom_copper);
    assert!(!app.show_silkscreen);
    assert!(!app.show_ratsnest);
}

#[test]
fn show_all_layers_enables_every_layer() {
    let mut app = PcbReviewerApp {
        show_top_copper: false,
        show_bottom_copper: false,
        show_silkscreen: false,
        show_ratsnest: false,
    };

    app.show_all_layers();

    assert!(app.show_top_copper);
    assert!(app.show_bottom_copper);
    assert!(app.show_silkscreen);
    assert!(app.show_ratsnest);
}
