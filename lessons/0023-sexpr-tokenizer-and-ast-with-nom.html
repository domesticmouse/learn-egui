0023. KiCad S-Expression Tokenizer & AST Inspector with nom

Extracting a standalone L0 kicad-sexpr parser crate with zero workspace or UI dependencies, composing nom parser combinators (delimited, many0, alt, take_while1) to build a recursive SexprNode syntax tree, and inspecting live KiCad .kicad_pcb trees with egui::CollapsingHeader.

Why KiCad Uses S-Expressions & Why Parsers Live at Layer L0

Real-world KiCad .kicad_pcb and .kicad_sch files store every board outline, net definition, footprint, pad, and copper trace segment as nested symbolic expressions (S-expressions):Standalone L0 Format Crates (egui-app-architecture): Principle #2 of our architecture requires format parsers like crates/kicad-sexpr to sit at Layer L0 (Standalone) with zero workspace or UI dependencies (validate_l0_standalone_manifest). That keeps the parser independently testable, fuzzable, and reusable across CLI tools, WebAssembly builds, and language servers.

(kicad_pcb
  (version 20240108)
  (net 1 "VCC_3V3")
  (footprint "SOT-23" (ref "U1") (val "LDO_3V3") (at 20.0 27.0) (size 12.0 16.0) (net 1))
  (pad "1" smd (at 20.0 22.0) (size 4.0 2.4) (layer "F.Cu") (net 1)))

Instead of hand-rolling fragile index-based character loops that can panic on UTF-8 boundaries or unclosed parentheses, we use nom—Rust's declarative parser combinator library. Every nom parser is a pure function fn(&str) -> IResult<&str, Output> returning Ok((remaining_input, parsed_value)) or a structured Err without panicking.

Scaffold the standalone crates/kicad-sexpr library crate and add nom, thiserror, and proptest with cargo add:

cargo new --lib crates/kicad-sexpr
cargo add --package kicad-sexpr nom@7.1.3 thiserror
cargo add --package kicad-sexpr --dev proptest
cargo add --package pcb-doc --path crates/kicad-sexpr

Recursive SexprNode Trees & nom Combinators in crates/kicad-sexpr

An S-expression has only three grammar productions:

  1. SexprNode::Symbol(String): An unquoted token of non-whitespace characters excluding (, ), and " (parsed by take_while1(is_symbol_char)).
  2. SexprNode::Quoted(String): A double-quoted string literal "..." (parsed by delimited(char('"'), take_while(|c| c != '"'), char('"'))).
  3. SexprNode::List(Vec<SexprNode>): A parenthesized list (...) containing zero or more whitespace-separated child nodes (parsed recursively by delimited(char('('), many0(delimited(multispace0, parse_node, multispace0)), char(')'))).

pub fn is_symbol_char(c: char) -> bool {
    !c.is_whitespace() && c != '(' && c != ')' && c 
}

fn parse_list_node(input: &str) -> IResult<&str, SexprNode> {
    map(
        (
            char('('),
            many0(delimited(multispace0, parse_node, multispace0)),
            char(')'),
        ),
        SexprNode::List,
    )(input)
}

pub fn parse_sexpr_str(input: &str) -> Result<SexprNode, SexprParseError> {
    let trimmed = input.trim();
    if trimmed.is_empty() {
        return Err(SexprParseError::);
    }
    match parse_node(trimmed) {
        Ok((rest, node)) => {
            let trailing = rest.trim();
            if trailing.is_empty() {
                Ok(node)
            } else {
                Err(SexprParseError::TrailingTokens(trailing.to_owned()))
            }
        }
        Err(_) => Err(SexprParseError::SyntaxError(trimmed.to_owned())),
    }
}
