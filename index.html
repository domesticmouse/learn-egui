Mission: Schematic & PCB Design Review System

Learn Rust & egui by Building a Schematic & PCB Design Reviewer

A hands-on, mutation-tested engineering course from immediate-mode fundamentals to an engine-first CAD architecture

Learning a new GUI framework from toy counter apps is easy. Building a real tool with a 2D CAD canvas, spatial hit-testing, and undo history is where things get interesting.

So, in this course, we are going to learn Rust and Emil Ernerfeldt's egui by building a Schematic & PCB Design Reviewer from scratch.Every lesson in this repository pairs an interactive HTML tutorial (with live in-browser simulators, code-completion labs, and retrieval quizzes) with a real, runnable Cargo project under ./apps/<NNNN-slug>/. Each lesson introduces one focused egui capability alongside one just-in-time Rust concept—and because we like keeping our sanity as the codebase grows, we verify our assertions continuously with cargo test and Martin Pool's cargo-mutants.

Five-Act Curriculum Progression: Every lesson builds toward a production Schematic & PCB Design Review System verified with unit tests and mutation coverage.

Running the Companion Rust Apps Locally

Every lesson is backed by a standalone, runnable Cargo package under ./apps/<NNNN-lesson-slug>/ that compiles with zero warnings and passes both cargo test and cargo mutants:

# Launch Lesson 0005's interactive PCB Reviewer desktop window
cargo run --manifest-path ./apps/0005-hit-testing-and-net-cross-probing/Cargo.toml

# Run unit tests and mutation coverage for Lesson 0005
cargo test --manifest-path ./apps/0005-hit-testing-and-net-cross-probing/Cargo.toml
cargo mutants -d ./apps/0005-hit-testing-and-net-cross-probing
